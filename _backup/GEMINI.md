# Project Context: 9xxxxxx.github.io

## Project Overview
This project is a personal website hosted on GitHub Pages (`9xxxxxx.github.io`). It currently consists of a basic static entry point (`index.html`).

**Main Technologies:**
*   HTML5

## Building and Running
As a static website, there is no build process required.

**To Run Locally:**
1.  Open `index.html` directly in a web browser.
2.  Alternatively, use a simple static file server:
    *   Python: `python -m http.server`
    *   Node.js: `npx http-server`

## Development Conventions
*   **Structure:** Flat directory structure with `index.html` as the entry point.
*   **Deployment:** Changes pushed to the `main` branch are automatically deployed by GitHub Pages.
